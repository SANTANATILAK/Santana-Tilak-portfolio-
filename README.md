# Santana Tilak — 8byte-tailored Portfolio

## Run locally
Open `index.html` in a browser.

## Deploy with GitHub Pages
1. Create a GitHub repository, e.g. `santana-portfolio`.
2. Upload `index.html`.
3. GitHub → Settings → Pages → Deploy from branch → `main` / root.
4. GitHub will provide your public portfolio URL.

## Important
The portfolio is tailored to the 8byte Python/AI Intern role. It only claims experience supported by the provided resume and presents additional 8byte-relevant technologies as areas of interest/growth rather than falsely claiming hands-on experience.
